# silero-clone-lite

Клонирование голоса для Silero TTS v5 (русский) по нескольким минутам записи. Без внешних голосовых энкодеров и без дообучения всей модели: подбираются вектор голоса и небольшое дообучение акустики (декодера).

**Чего ожидать.** Голос получается узнаваемым по тембру и манере, но это не студийный клон: интонация и длительности остаются «силеровскими», на непохожих фразах может плыть. Для хорошего результата нужны чистые записи одного диктора без музыки и шума.

## Установка

```bash
pip install -r requirements.txt
```

Модель Silero скачайте сами с официального сайта проекта Silero ([github.com/snakers4/silero-models](https://github.com/snakers4/silero-models), файл `v5_ru.pt`) и положите в корень репозитория. В репозитории её нет, её лицензия принадлежит авторам Silero, см. раздел «Лицензии».

## Использование

1. Положите записи голоса (`.wav`, 2–4 минуты суммарно, фразы по 3–15 секунд) в `voices/myvoice/`.
2. Распознайте текст (он сохранится в `voices/myvoice/transcripts.json`, при необходимости поправьте его руками):
   ```bash
   python transcribe.py myvoice
   ```
3. Подберите вектор голоса:
   ```bash
   python clone_voice.py myvoice
   ```
4. (Необязательно, сильно улучшает узнаваемость) аккуратно дообучите акустику (декодер):
   ```bash
   python extended_voice.py train myvoice --start voices/myvoice/myvoice_clone_v5_ru.pt --tag dec
   ```
5. Синтезируйте речь:
   ```bash
   python synth.py --voice voices/myvoice/myvoice_extended_dec.pt                    --text "Здравствуйте, это проверка голоса." --out out.wav
   ```

Нужна видеокарта с CUDA; на CPU всё работает, но очень медленно.

**Про объём данных.** На 2–3 минутах (около 20 клипов) дообучение быстро упирается в переобучение и останавливается само (на Дане лучшая точка была на ~1000 шаге). Чем больше чистых записей, тем лучше результат.

## Как это работает

Silero v5 держит голос в двух векторах: тембр акустики (128 чисел) и по 64 числа для предикторов длительностей и высоты тона. Скрипт `clone_voice.py` разбирает модель на дифференцируемые части (текст → длительности/питч → мел → вокодер) и подбирает эти числа градиентом так, чтобы синтез совпадал с вашей записью (мультимасштабный STFT-лосс + log-mel). Выравнивание записи и текста делается через DTW.

## Известные ограничения

- Только русский и только `v5_ru` (остальные модели Silero не проверялись).
- Качество зависит от записей: эхо, музыка и сжатие сильно ухудшают результат.
- Текст из Whisper нужно вычитывать: цифры, ударения и «ё» влияют на результат.
